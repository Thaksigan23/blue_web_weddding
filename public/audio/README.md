# Wedding music

The active `wedding-music.mp3` is the existing romantic track copied from the
previous wedding invitation (`dheeni-premantara.mp3`). The user selected this
available romantic track on 28 October 2026.

The traditional `nadaswaram-bgm.mp3` is retained as an unused alternative.
Both original source files are unchanged. Guests start/pause music from the
navigation bar or standalone desktop music control. Audio loads on demand,
loops at a gentle initial volume, and never autoplays. Device volume controls
remain available; no on-page volume slider is shown.
